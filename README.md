# 🌙 Nightcore Studio — by Synapx

A free, browser-based Nightcore converter. No server, no uploads — everything runs locally in your browser.

🔗 **Live site:** [NafizAhmed.github.io/nightcore-studio](https://NafizAhmed.github.io/nightcore-studio)

## Features

- Upload any audio file (MP3, WAV, OGG, FLAC, AAC, M4A)
- Live preview — hear changes in real-time as you move sliders
- Speed, Pitch, Bass Boost & Reverb controls
- 5 presets: Classic, Hyper, Dreamy, Hard Bass, Daycore
- Export as WAV
- 100% client-side — your files never leave your device

## Deploy to GitHub Pages

1. Fork or upload this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch → main → / (root)**
4. Save — your site will be live at `https://your-username.github.io/nightcore-studio`

## Tech

Pure HTML + CSS + JavaScript. Uses the Web Audio API for real-time audio processing.
